# 🏥 MediCare - Hospital Management System (HMS)

**MediCare** is a modern, professional, and fully responsive digital solution developed to streamline hospital operations. It manages patient records, doctor schedules, pharmacy inventory, and medical history with a sleek, user-friendly interface.

---

## 🌍 Luuqadaha / Supported Languages
- 🇬🇧 **English** (Primary)
- 🇸🇴 **Af-Soomaali** (Translation Included)

---

## 🚀 Key Features (English)
- **📈 Advanced Dashboard:** Real-time metrics for revenue, patient demographics, and staff status.
- **📁 Patient Management:** Comprehensive registration system with 100+ record viewing capacity per page.
- **📄 Medical Records & Timeline:** A chronological archive of every prescription, lab test, and visit.
- **⚕️ Digital Prescriptions:** Professional PDF-style prescriptions with manual entry and printing support.
- **💊 Pharmacy & Inventory:** Tracking medicine stock, expiry dates, and daily sales logs.
- **📱 Ultra-Responsive:** Optimized for iPhone, Samsung, Tablets, Desktops, and large TV displays.
- **🔐 Secure Access:** Role-based authentication (Admin/Worker) with JWT and MongoDB.

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS, Lucide Icons, Recharts.
- **Backend:** Node.js, Express.js, MongoDB (Mongoose), Joi Validation.
- **Auth:** JSON Web Tokens (JWT), Bcrypt.js.

---

## 📥 Installation

1. **Clone the repo:**
   ```bash
   git clone https://github.com/yourusername/hospital-system.git
   ```

2. **Setup Backend:**
   ```bash
   cd backend
   npm install
   # Create .env with MONGO_URI, JWT_SECRET, PORT
   npm run dev
   ```

3. **Setup Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
