# 🏥 Sida Loo Bilaabo Hospital System

## Dhibaatada: "Server-ka la xiriiri kari waydey"

**Sababta:** Backend server-ka ma socdaan. Waa inuu socdaa si frontend ugu xiriirto.

---

## Tallaabooyinka (2 terminal)

### 1. Backend (Terminal 1)
```bash
cd backend
npm run dev
```
Waa inuu soo baxaa: `🚀 Server: http://localhost:5000`

### 2. Frontend (Terminal 2)
```bash
cd frontend
npm run dev
```

### 3. MongoDB
Hubi in MongoDB socdo (MongoDB Compass ama MongoDB service).

---

## Hab Fudud: Labadaba Isla Socda

Folder-ka root-ka:
```bash
npm install
npm run dev
```
Wuxuu bilaabayaa backend iyo frontend isla markiiba.
